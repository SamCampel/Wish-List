🌟 Wish List: Aprendendo com HTML e CSS

Desenvolvi uma wish list (lista de desejos) usando apenas HTML e CSS! Este projeto foi uma ótima oportunidade para praticar conceitos como:

    Estrutura semântica com HTML.

    Estilização responsiva com CSS.

    Uso de flexbox para alinhamento e organização dos itens.

A lista permite adicionar, visualizar e "riscar" desejos concluídos, tudo com uma interface simples e intuitiva. Foi um ótimo exercício para consolidar meus conhecimentos em desenvolvimento front-end!
